本次更新（自 build 39 以来）

【新功能】快捷操作管理页
主页 Hub 右上角的按钮从 "+ 新建" 改成 "管理"。点进去能：

- 一眼看到所有动作（自建 + 系统 + 导入的），每条带 "在槽 N" 或
  "未分配" 标签——再也不用记哪些挂在主页上、哪些没挂上
- 槽位区每个 tile 角上有 × 按钮，一键从主页槽位移走但保留动作
- 直接拖动槽位上的 tile 调换位置
- 左滑或编辑器里删除自建动作
- "重置为默认" 按钮，一键回到锁车 / 解锁 / 预热 / 后备箱 4 个
  默认动作的初始状态

之前要做这些事得分散在主页长按菜单 + 三个不同 sheet 之间，
现在一个页面搞定。

【说明】系统动作（锁车 / 解锁 / 预热 / 后备箱）依然能编辑
名字、图标、颜色，但不能删除——为了不让你不小心把主功能
清空了。
