本次更新（自 build 37 以来）

🎯 新功能：主页快捷操作
8 个可自定义按钮直接挂在 Hub 主页。默认预置 4 个常用动作（锁车 /
解锁 / 预热 / 后备箱），剩余 4 个空位你自己填。

- 长按 tile 编辑（改名、换图标 32 选 1、换颜色 5 选 1）
- 单步动作 = 一个 Tesla 命令；最多 5 步串成 macro（"离家模式" =
  锁车 → 关空调 → 哨兵，可设步间延迟）
- 敏感动作（解锁、预热）默认要二次确认
- "管理" 按钮快速建新动作
- 多端同步：iOS / Android（Android v 待发）共用同一份配置

🚗 主页正确显示车名
之前部分用户看到 "Tesla" / "我的 Tesla"。已修：Tesla Fleet API 返
回的 display_name 直接穿透显示。如果在 Tesla 官方 app 里把车
命名为 "黑胖子"，主页就显示 "黑胖子"。

🔌 充电站详情升级
- 充电站照片轮播（2-5 张高德 CDN 图）
- 高德评分徽章（⭐ 4.4）
- 营业时间（24h 标识 + 具体时段）
- "在高德地图打开" 用入口坐标导航（路边充电站不再偏 50-100m）
- 规划路线后，沿途充电站每一项可点击展开详情

🎨 主页布局清爽
入口卡（下次出行 / 充电规划 / 自动化 / 电池管理）只显示标题，
小字注释挪到二级页（详情按需展开）。"唤醒中 3/10" 改成 "连接中"，
减少干扰。

🐛 修了登录偶发失败
之前少数情况下 OAuth 跳回会卡在 "未能从登录回调中提取凭证"，根因
是服务端多 worker 模式下 OAuth state 不共享。已迁到 DB 持久化，
任何 worker 都能找到对应 session。
