## 1. 服务说明

Tautomation 是一款面向 Tesla 车主的第三方自动化辅助工具。主要功能包括：

- 通过 Tesla 官方 OAuth 授权读取车辆状态
- 配置基于车辆状态的自动化规则（如哨兵超时提醒、充电完成通知）
- 出行计划与提前预热提醒
- 充电限额设置、充电会话统计
- 车辆控制命令转发（设置充电上限、空调、哨兵模式等）
- 充电规划与沿途充电站推荐（**内测功能，正式版可能未开放**）

账户安全负责。"Tesla" 商标归 Tesla, Inc. 所有。

### 2.2 车辆控制命令的风险

本应用提供向你的 Tesla 车辆下发命令的功能（如启动空调、设置充电上限、
切换哨兵模式等）。**你完全理解并接受**：

- 上述命令通过 Tesla Fleet API + 车辆命令协议（VCP）执行，**会对你的
  车辆产生实际物理影响**
- 命令的下发与执行之间可能存在网络延迟、Tesla API 故障或车辆未联网等
  导致的失败或延后
- **请勿将本应用作为安全关键任务的唯一依据**——例如，不要依赖本应用
  的"哨兵已关闭"提醒来确认车辆真实安全状态
- **请勿在驾驶过程中操作本应用**
- 因下发命令导致的车辆物理状态变化、电费、能量损耗、空调运行后的电
  量变化等，均由你自行承担

### 2.3 自动化规则的风险

自动化规则按你配置的阈值在后台运行。我们不为以下情况负责：

- 推送通知延迟、丢失或重复推送
- 自动化规则错误触发或未触发
- 与 Tesla 车机自带自动化（Routines）功能的冲突

如你对 Tesla 自带功能与本应用同时配置了相同类型规则，可能产生重复通
知或互相覆盖。我们已在应用内对常见冲突场景给出提示，但**最终配置一致
性需由你自行管理**。

## 3. 账号注册与使用

### 3.1 登录方式

本应用**仅支持** Tesla OAuth 登录，不支持邮箱/密码、手机号或其他第三方
账号。Tesla 账号本身的安全（密码、二次验证等）由 Tesla 负责。

### 3.2 账号绑定

- 一个 Tesla 账户可登录多台设备
- 我们通过 VIN 识别车辆，同一车辆首次绑定的账户即为车辆持有者
- 不得使用他人的 Tesla 账户登录本应用

### 3.3 账号注销

进入「设置 → 危险操作 → 删除账号」可立即注销账号。详见
[隐私政策第 5 节](privacy-policy.md#5-你的权利)。
