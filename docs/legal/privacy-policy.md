# Tautomation 隐私政策

**生效日期：** 2026-05-15
**版本：** v1.0

本隐私政策说明 Tautomation（以下简称"我们"或"本应用"）在你使用本应用过程中
如何收集、使用、存储、共享和保护你的个人信息，以及你享有的相关权利。

请你**在使用本应用前仔细阅读本政策**。一旦你完成 Tesla OAuth 授权登录并开始使
用，即视为同意本政策的全部内容。

---

## 1. 信息收集

### 1.1 你通过 Tesla 授权提供给我们的信息

本应用使用 **Tesla 官方 Fleet API** 进行登录与车辆数据交互。在你通过
Tesla 官方 OAuth 授权后，我们会收到：

- Tesla 账户 ID（用于识别你与车辆的绑定关系）
- 你向 Tesla 授权我们读取/操作的车辆数据，包括但不限于：
  - 车辆 VIN、车型、显示名称、软件版本
  - 实时位置（经纬度，**仅在你使用充电规划、自动化规则需要时读取**）
  - 充电状态（电量、充电限额、是否在充电、连接状态）
  - 空调状态（温度、空调保持模式、座舱过热保护）
  - 安全状态（哨兵模式、车门/车窗/前后备箱开闭、上锁状态）
  - 驾驶状态（档位、车速）
- 我们**不会**收集你的 Tesla 账户密码——OAuth 流程在 Tesla 官方域名完成，
  我们只接收授权令牌（access token / refresh token）。

### 1.2 你直接在应用内创建的信息

- 自动化规则配置（如"哨兵开启超过 2 小时提醒"的阈值、动作）
- 出行计划（下次出行时间、提前预热分钟数、目标 SOC）
- 充电限额偏好（日常上限、出行上限）
- 充电会话记录（开始/结束时间、起止电量、能量、地点）
- 路线规划历史（起点、终点、沿途充电站选择）
- 应用内设置项（UI 偏好、卡片显示开关等）

### 1.3 设备与推送相关信息

- 设备推送 token（Apple 推送通知服务 APNs），用于向你发送自动化告警
  与出行预热提醒
- 应用版本号、操作系统版本、设备型号（仅在服务器日志中出现，用于故障
  诊断）

### 1.4 我们**不**收集的信息

- 你的姓名、身份证号、手机号、邮箱密码、支付信息
- 你的通讯录、相册、相机、麦克风、健康数据
- 你的位置（除车辆位置外）——本应用**不读取手机本身的 GPS**

## 2. 信息使用

我们仅在下列目的范围内使用上述信息：

| 用途 | 用到的信息 |
|---|---|
| 在 Hub 页展示车辆状态 | Tesla 授权的车辆数据 |
| 自动化规则评估与推送告警 | 车辆状态 + 你配置的规则 + 推送 token |
| 充电规划与导航发送 | 车辆位置、电量、沿途充电站、目的地 |
| 出发前预热提醒 | 出行计划 + 推送 token |
| 充电统计与限额建议 | 充电会话历史 + 车辆电量 |
| 故障诊断与产品改进 | 服务器匿名日志（不含车辆位置） |

我们**不会**将上述信息用于广告投放、用户画像出售、商业推销，也**不会**
用于训练第三方机器学习模型。

## 3. 信息存储

### 3.1 存储地点

- 服务端数据存储于**腾讯云中国大陆境内服务器**（API 域名
  `api.teplanner.cloud`）。
- 你的 Tesla 访问令牌在服务器存储时**加密**保存。
- 设备本地保存：访问令牌（保存在 iOS Keychain）、UI 偏好（保存在
  UserDefaults）。

### 3.2 保留期限

- **账户数据**（自动化规则、出行计划、设置等）：自你最后一次活动起
  保留 12 个月，超过则归档冷存储。你随时可以通过"删除账号"立即清除。
- **充电会话历史**：保留 36 个月，便于长周期统计。
- **服务器请求日志**：保留 30 天。
- **OAuth 临时状态**（验证码、重定向 token）：10 分钟。

## 4. 信息共享与第三方 SDK

本应用涉及以下第三方服务，每项均仅在功能所需时使用必要数据：

### 4.1 Tesla Fleet API（Tesla, Inc.）

- **用途**：读取车辆状态、向车辆下发命令（如设置充电上限、启动空调）。
- **共享数据**：Tesla 授权令牌、命令参数（如目标电量百分比）。
- **隐私政策**：https://www.tesla.com/legal/privacy

### 4.2 高德地图（Amap, 阿里巴巴）

- **iOS SDK 版本**：用于地图渲染、附近充电站搜索、沿途 POI 搜索。
- **Web Service 版本**：服务端用于路线规划、地理编码、反向地理编码。
- **共享数据**：起点 / 终点经纬度、当前位置经纬度、搜索关键词。
- **隐私政策**：https://lbs.amap.com/pages/privacy/

### 4.3 Apple 推送通知服务（APNs）

- **用途**：向你的设备投递自动化告警、出行预热提醒。
- **共享数据**：推送 token、推送内容摘要（不含敏感字段）。
- **隐私政策**：https://www.apple.com/legal/privacy/

### 4.4 腾讯云

- **用途**：服务端基础设施（计算、网络、存储）。
- **共享数据**：所有服务端数据均在腾讯云境内服务器上运行。
- **隐私政策**：https://privacy.qq.com

我们**不会**将你的信息以可识别方式提供给上述名单以外的任何第三方。

## 5. 你的权利

你享有以下权利。如需行使，可通过应用内或第 8 节联系方式联系我们：

1. **查询**：你可以在应用内查看所有自动化规则、出行计划、充电记录。
2. **更正**：自动化规则、出行计划随时可在应用内修改。
3. **删除**：
   - 单条数据：在应用内对应入口删除
   - **整个账号**：进入「设置 → 危险操作 → 删除账号」，二次确认后服务器
     端的所有数据将被永久删除。**此操作不可恢复，且不会影响你的 Tesla
     账户**（Tesla 账户需自行到 tesla.com 操作）。
4. **撤回授权**：可随时到
   [Tesla 账户设置](https://www.tesla.com/account-settings) 撤回对本应用
   的授权，撤回后我们将无法再读取你的车辆数据。
5. **导出**：如需获取你的账号数据副本，请通过第 8 节联系方式发邮件申请，
   我们会在 15 个工作日内向你提供 JSON 格式的导出文件。
6. **投诉**：如认为我们的处理违反法律，可向有关监管部门投诉。
